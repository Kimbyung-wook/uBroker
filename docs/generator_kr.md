# 코드 생성기

[English](generator.md) | 한국어

`code_gen/ubroker_gen.py`는 `.msg` 파일을 읽어 C 코드를 만듭니다. Python 3.6 이상이 필요하고 표준 라이브러리만 사용합니다.

## 실행

```
python code_gen/ubroker_gen.py -i <msg 폴더> -o <출력 폴더> [--lang en|ko]
```

| 옵션 | 설명 |
|---|---|
| `-i`, `--input` | `.msg` 파일이 있는 폴더 (필수) |
| `-o`, `--output` | 생성 파일을 저장할 폴더 (없으면 만듦, 필수) |
| `--lang en\|ko` | 오류 메시지와 `--help`의 언어 (기본 `en`). 생성 코드의 주석은 항상 영문 |

종료 코드: 성공 `0`, 오류 `1`

## 출력 파일

| 파일 | 내용 |
|---|---|
| `<msg>.h` | 구조체 `<msg>_t`, 상수, `<MSG>_INITIALIZER` |
| `ubk_msgs.h` | 모든 메시지 헤더 include, 토픽 ID `ubk_topic_id_t`, 토픽 정보 테이블 선언 |
| `ubk_msgs.c` | 메시지 기본값, 토픽 공유 메모리, 토픽 정보 테이블 `g_ubk_topic_meta[]` |

`core/`의 `ubk_types.h`, `ubroker.h`, `ubroker.c`는 생성하지 않습니다. 그대로 빌드에 넣으면 됩니다.

빌드 설정:
- include 경로: `core/`, 출력 폴더
- 소스: `core/ubroker.c`, `<출력 폴더>/ubk_msgs.c`

생성 파일 첫 줄에는 다음 안내가 들어갑니다.

```c
/* Auto-generated by ubroker_gen.py from weapon_state.msg. DO NOT EDIT. */
```

생성 파일은 직접 고치지 말고, `.msg`를 고친 뒤 다시 생성하세요.

## 증분 생성

- 내용이 바뀐 파일만 다시 씁니다. 파일마다 `updated` / `unchanged`로 알려 주므로 빌드 시스템은 바뀐 것만 다시 컴파일합니다.
- 토픽을 추가하거나 삭제하면 `ubk_msgs.h`(토픽 ID)가 바뀌므로 이를 include한 소스는 다시 컴파일됩니다.
- `.msg` 파일을 지우면 그 생성 헤더를 지웁니다 (`removed`). 생성기 안내 줄로 시작하는 `.h`/`.c`만 지우므로 출력 폴더의 사용자 파일은 안전합니다.

```
  unchanged sensor_imu.h
  updated   weapon_state.h
  updated   ubk_msgs.h
  unchanged ubk_msgs.c
  removed   old_msg.h
```

## 생성 전 검사

모든 파일을 먼저 검사합니다. 오류가 하나라도 있으면 파일을 쓰지도 지우지도 않습니다.

- 문법 오류, 필드 없는 메시지
- 알 수 없는 타입, 중첩 메시지 순환 참조
- 기본값 형식과 범위, 배열 기본값 개수
- 비트필드 타입·폭·채움
- 이름 규칙: snake_case, 첫 글자, 31자 제한, C 예약어, `ubk_` 접두어, 예약 이름, 중복
- 토픽 이름 중복, `TYPE_ONLY`와 `TOPICS` 동시 사용

예 (`--lang ko`):

```
msg/weapon_state.msg:8: error: 비트 폭은 1 ~ 8 이어야 합니다
msg/sensor_imu.msg:9: error: 비트필드 그룹(is_calibrated~)이 uint8 저장 단위를 채우지 않습니다 (7/8 bit 사용). 남는 비트는 reserved 필드로 명시하세요
2 error(s). 생성하지 않았습니다.
```

규칙 자체는 [`msg_syntax_kr.md`](msg_syntax_kr.md)를 참고하세요.
